# CMPE 258 Project Proposal Assignment (as given)

The goal of the project proposal is to clearly define the topic, motivation, goals, and technical plan for your semester-long project. This proposal helps ensure your project is feasible, well-scoped, and technically meaningful.

The submission must include the following four core deliverables (AI Assistance Allowed):

A. GitHub Repository Link
Your repository must include an initial README.md containing the project title, team members' names, abstract, and selected track.

B. Literature & SOTA Survey Results (GitHub)
Summarize at least 5 to 10 recent papers/models published within the last 1–3 years relevant to your topic.

C. Project Proposal Document (Canvas)
Problem Formulation: Clear statement of the domain problem, input/output specifications, and target metrics/success criteria.

Proposed Technical Approach: High-level architecture, chosen models, data sources, and intended technical modifications or advanced system capabilities.

D. AI Novelty & Feasibility Audit (GitHub)
AI Critique Summary: Paste the AI's evaluation regarding your project's novelty, potential "red ocean" risks, or oversaturated areas.
